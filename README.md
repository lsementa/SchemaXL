# SchemaXL

[SchemaXL](https://lsementa.github.io/SchemaXL/) is a browser-based file-to-Excel conversion tool that transforms raw data into a clean, structured Excel or CSV file.

## Features

- Supports CSV, TXT, JSON, and XML
- Configure column mappings, data types, and structure
- No uploads or servers
- Can handle very large files
- Save reusable schemas as `.sxl` files
- Reload saved schemas to process updated source files

## Privacy & Performance

SchemaXL runs entirely on your device. Your files are never uploaded or sent to a server.

Large datasets are processed using streaming techniques, allowing imports and exports without loading everything into memory at once. This enables SchemaXL to work efficiently even with very large files.
